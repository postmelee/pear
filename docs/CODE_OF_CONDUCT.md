# Code of Conduct

Pear welcomes people of every background, identity and experience level. This
policy applies to repository Issues, pull requests, Discussions and spaces where
someone represents the project.

## Expected behavior

Be respectful and specific. Critique ideas and code rather than people. Respect
others' time, privacy, accessibility needs and right to disagree. Accept
constructive feedback, acknowledge mistakes and correct misleading claims.

Harassment, discriminatory or sexualized remarks, threats, doxxing, unwanted
contact, deliberate disruption and publication of another person's private
information are not acceptable. Do not pressure anyone to share credentials,
proprietary files or private diagnostics.

## Reporting

Use the content menu on GitHub to **Report content / Report abuse to GitHub
Support**, or GitHub's [private abuse reporting form](https://support.github.com/contact/report-abuse).
See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Avoid repeating private information in a public reply.

Where GitHub offers reporting directly to repository administrators, that option
can be used. It depends on repository ownership/settings and is not currently
established for Pear. A report to GitHub Support goes to GitHub, not automatically
to Pear maintainers. This policy does not promise a separate private maintainer
inbox. Security vulnerabilities use the [security policy](SECURITY.md) instead.

## Moderation

Maintainers can request a correction, remove or edit disruptive content, lock a
conversation, or temporarily/permanently restrict participation, depending on
severity and repetition. Serious threats or privacy violations can warrant
immediate restriction. Explain decisions when doing so does not expose private
information; handle reports fairly and limit disclosure to what resolution needs.
GitHub separately enforces its platform policies. A report involving a maintainer
can be sent directly to GitHub Support through the same private abuse route.
