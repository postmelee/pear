## Local consent model
ReportingPolicy.swift is a transport-independent Codable model, not yet integrated
into the app. Default local-only; separate prompt and notification flags; explicit
field projection with no exact timestamps, paths/accounts/log schema; process
minutes distinct from gameplay; unknown result/exit retained. Notes require manual
explicit selection. Immutable request IDs support retry; revision increases while
report ID stays the same. Changing consent invalidates queued automatic payloads;
manual requests remain possible. Codable round trip preserves withdrawal.

Native Swift checks passed for default silence, prompt suppression without consent,
selected fields, note exclusion, stable retry identity, same-report revision,
withdrawal and restart, and changed-field invalidation. Added to existing macOS
build checks. This does not yet prove file persistence, network cancellation,
observer lifetime, actual app UI or server access control. Those remain required.
