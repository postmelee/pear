# Profile implementation rules

Read the root rules, runtime contracts, approved task plans and tests/AGENTS.md.

- Profiles use the existing versioned game-profile contract; no executable scripts or alternate profile format.
- Keep fixture profiles redistributable and distinct from real game qualification. No proprietary files, credentials, authenticated prefixes or personal saves belong here.
- Preserve explicit unknown/untested observations. A profile does not grant runtime or signing authorization.
- Only approved typed operations may execute. Manager-owned prefix/work bindings cannot be overridden.
- Keep relative save mappings separate from immutable runtime files. Recovery preserves prior contexts and saves.
